# Каталог асан

Веб-приложение для управления и просмотра каталога асан традиционных школ йоги: мультиязычные названия, фотографии, источники, экспертная модерация и ИИ-подсказки для связей `isSameAs`.

**Production:** [catalog-asan.ru](https://catalog-asan.ru)

Подробнее об инфраструктуре и деплое — в [корневом README](../README.md).

## Возможности

- **Каталог** — поиск (нечёткий), алфавитная навигация, фильтр по источникам.
- **Источники** — книги и публикации, привязка асан.
- **Справочник названий** — отдельный раздел для экспертов и админов.
- **Роли** — гость (просмотр), эксперт (редактирование контента), администратор (пользователи, аудит, мониторинг).
- **Импорт/экспорт Excel** — асинхронный импорт через отдельный сервис.
- **Модерация** — очередь проблемных записей после импорта.
- **ИИ-модерация** — предложения связей `isSameAs` по pHash и YOLO yoga-82.
- **Профиль** — смена пароля и аватара.
- **Восстановление пароля** — OTP-код на email, двухшаговый сценарий с чеклистом требований к паролю.
- **Админ-панель** — пользователи, аудит действий, ссылки на Grafana/Kibana/Swagger.

Самостоятельная регистрация на сайте **отключена** — учётные записи создаёт администратор.

## Структура

```text
asana-dict-service/
├── backend/              # API каталога (FastAPI)
├── import-service/       # воркер импорта/экспорта (Redis)
├── frontend/             # SPA (React + Vite)
├── docs/                 # дополнительная документация
├── ИНСТРУКЦИЯ_ДЛЯ_ЭКСПЕРТОВ.md   # seed для страницы «Инструкции»
└── О_ПРОЕКТЕ.md          # seed для страницы «О проекте»
```

Связанные сервисы в монорепозитории:

- `asana-server-module` — авторизация, пользователи, SMTP, сброс пароля;
- `asana-network-service` — ИИ-обработка изображений;
- `backup-runner` — ежедневные бэкапы БД, OWL и S3 → Google Drive.

## Запуск

Рекомендуемый способ — **Docker Compose из корня** `asana-services`:

```bash
cd asana-services
cp .env.example .env   # заполните переменные
docker compose up -d --build
```

Сайт: `http://localhost`  
API: `http://localhost/api/...`

### Frontend отдельно (разработка)

```bash
cd frontend
npm install
npm run dev
```

Сборка: `npm run build`. Подробнее — [frontend/README.md](frontend/README.md).

## Документация для экспертов

- **В интерфейсе:** раздел **«Инструкции»** (доступен экспертам и админам).
- **В репозитории:** [ИНСТРУКЦИЯ_ДЛЯ_ЭКСПЕРТОВ.md](ИНСТРУКЦИЯ_ДЛЯ_ЭКСПЕРТОВ.md).

При первом запуске backend подхватывает markdown из `/app/seed_content/` (volume в `docker-compose.yml`). Администратор может править текст в UI; API `POST /api/expert-instructions/reset-from-md` восстанавливает текст из файла.

## API

- Swagger (production, только админ): `/api/docs`
- Основной API каталога: `/api/*` → `asana-backend`
- Auth и пользователи: `/api/auth/*`, `/api/users/*` → `server-module`
- Импорт: `/api/import/*`, `/api/export/*` → `asana-import`

Маршрутизация настраивается в `nginx.conf` / `nginx.prod.conf`.
