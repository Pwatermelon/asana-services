## Диаграммы

### Use Case диаграмма
Файл: `use_case_diagram.mmd`

Для конвертации в изображение:
1. Используйте онлайн-сервис https://mermaid.live/ или установите Mermaid CLI
2. Скопируйте содержимое файла `use_case_diagram.mmd`
3. Вставьте в редактор Mermaid
4. Экспортируйте как PNG или SVG

Или используйте команду:
```bash
mmdc -i use_case_diagram.mmd -o use_case_diagram.png
```

### Диаграмма архитектуры
Файл: `architecture_diagram.mmd`

Аналогично Use Case диаграмме, используйте Mermaid для конвертации в изображение.

### Альтернативные варианты

Если Mermaid не подходит, можно использовать:
- Draw.io (https://app.diagrams.net/) - импорт Mermaid или создание вручную
- PlantUML - конвертация Mermaid в PlantUML
- Visio - создание диаграмм вручную на основе структуры из Mermaid файлов

## Рекомендации по вставке в документ

1. **Use Case диаграмма** должна быть вставлена в раздел 1.6 после текста о диаграмме

3. Размер изображений рекомендуется: ширина 14-16 см для A4 формата
4. Подписи к рисункам должны быть оформлены согласно требованиям: "Рисунок 1 - Диаграмма использования системы", "Рисунок 2 - Архитектура системы"
