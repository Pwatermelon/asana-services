# Yoga Dict Android App

Красивое Android приложение для работы с каталогом асан, подключающееся к вашему dict-service backend.

## 🚀 Особенности

- ✨ Современный UI на Jetpack Compose
- 🎨 Material Design 3
- 🔍 Поиск асан
- 📱 Адаптивный дизайн
- 👆 Жесты (long press для контекстного меню)
- 🖼️ Загрузка изображений через Coil
- 🔄 Pull-to-refresh
- 📋 Алфавитная навигация

## 📋 Требования

- Android Studio Hedgehog или новее
- JDK 17
- Min SDK: 24 (Android 7.0)
- Target SDK: 34 (Android 14)

## ⚙️ Настройка

1. **Настройка адреса сервера** в `app/build.gradle.kts`:
```kotlin
buildConfigField("String", "API_BASE_URL", "\"https://katalog-asan.online\"")
```

   - **Производственный сервер:** `https://katalog-asan.online` (уже настроено)
   - **Для локальной разработки:**
     - Эмулятор: `http://10.0.2.2:80` (10.0.2.2 - специальный IP для доступа к хосту из эмулятора)
     - Реальное устройство: `http://192.168.1.X:80` (IP вашего компьютера в локальной сети)
   
   **Как узнать IP компьютера для локальной разработки:**
   - Windows: выполните `ipconfig` в командной строке, найдите IPv4 адрес
   - Linux/Mac: выполните `ifconfig` или `ip addr`, найдите IP в локальной сети

2. **Убедитесь, что backend запущен** и доступен по указанному адресу

3. **Откройте проект** в Android Studio и синхронизируйте Gradle

## 🏗️ Сборка

```bash
./gradlew assembleDebug
```

Или через Android Studio: Build → Make Project

## 📱 Установка

```bash

```

## 🎯 Использование

### Для всех пользователей:
1. **Авторизация**: Войдите или зарегистрируйтесь
2. **Просмотр асан**: Просматривайте список асан с поиском и алфавитной навигацией
3. **Детали асаны**: Нажмите на асану для просмотра деталей с фотографиями
4. **Источники**: Просматривайте список источников литературы
5. **Асаны по источнику**: Просматривайте асаны из конкретного источника
6. **О проекте**: Информация о проекте
7. **Жесты**: Долгое нажатие открывает контекстное меню

### Для экспертов и админов:
- **Добавление асан**: Добавляйте новые асаны с фотографиями
- **Добавление источников**: Добавляйте новые источники литературы
- **Модерация**: Обрабатывайте записи на модерацию
- **Настройки**: Управление системой
- **Инструкции**: Инструкции для экспертов

## 🏗️ Архитектура

- **MVVM** - Model-View-ViewModel
- **Hilt** - Dependency Injection
- **Retrofit** - HTTP клиент
- **Coil** - Загрузка изображений
- **Navigation Compose** - Навигация

## 📦 Основные компоненты

- `AsanaListScreen` - Список асан с поиском и фильтрами
- `AsanaDetailScreen` - Детальная информация об асане
- `AsanaViewModel` - Управление состоянием
- `DictApiService` - API клиент для backend

## 🔧 Настройка backend

Убедитесь, что ваш dict-service backend:
- Запущен и доступен по указанному IP
- Разрешает CORS запросы (если нужно)
- API endpoints соответствуют ожидаемым
