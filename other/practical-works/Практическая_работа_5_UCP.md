# Практическая работа 5. Оценка проекта методом UCP (Use Case Points)

## Цель работы
Изучить основы применения метода вариантов использования (Use Case Points) для измерения размера и оценки стоимости разработки проекта "Каталог асан".

## Описание проекта

**Проект:** Веб-приложение "Каталог асан" - информационная система для хранения и управления информацией об асанах йоги.

## 1. Классификация исполнителей (Unadjusted Actor Weight - UAW)

**Таблица 5.1 - Классификация актеров системы**

| № | Актер | Тип | Вес | Количество | Вклад |
|---|-------|-----|-----|------------|-------|
| 1 | Гость (веб-браузер) | Complex | 3 | 1 | 3 |
| 2 | Эксперт (веб-браузер) | Complex | 3 | 1 | 3 |
| 3 | Администратор (веб-браузер) | Complex | 3 | 1 | 3 |
| 4 | Сервис авторизации (REST API) | Simple | 1 | 1 | 1 |

| **Итого UAW** | | | | | **11** |

**Обоснование:**
- Гость, Эксперт, Администратор - взаимодействуют через веб-интерфейс (Complex, вес 3)
- Сервис авторизации, MinIO/S3 - внешние системы с предопределенным API (Simple, вес 1)

## 4. Оценка внешних факторов (Environmental Complexity Factor - ECF)

**Таблица 5.4 - Оценка факторов внешней среды**

| Фактор | Описание | Оценка (0-5) | Вес | Вклад |
|--------|----------|--------------|-----|-------|

**Расчет ECF:**
```
ECF = 1.4 + (-0.03 × EF) = 1.4 + (-0.03 × 21.5) = 1.4 - 0.645 = 0.755
```

## 5. Окончательный расчет UCP

**Расчет UCP:**
```
UCP = (UAW + UUCW) × TCF × ECF
UCP = (11 + 145) × 1.06 × 0.755
UCP = 156 × 1.06 × 0.755 = 156 × 0.8003 = 124.85 ≈ 125 UCP
```

## 6. Оценка трудоемкости разработки

**Оценка часов на один вариант использования:**
- Простые варианты: 20 часов
- Средние варианты: 25 часов
- Сложные варианты: 30 часов

**Расчет общей трудоемкости:**
```
Трудоемкость = (4 × 20) + (5 × 25) + (5 × 30) = 80 + 125 + 150 = 355 часов
```

**Или через UCP:**
```
Трудоемкость = UCP × часы на UCP = 125 × 2.84 = 355 часов
```

**Перевод в чел×мес:**
```
При 160 рабочих часах в месяц: 355 / 160 = 2.22 чел×мес
```

**Время разработки:**
```
При команде из 2 человек: 2.22 / 2 = 1.11 месяца
При команде из 3 человек: 2.22 / 3 = 0.74 месяца
```

## 7. Сравнительный анализ методов оценки

**Таблица 5.5 - Сравнение методов оценки**

| Метод | Трудоемкость (чел×мес) | Время (мес) | Размер команды |
|-------|------------------------|-------------|----------------|
| COCOMO II (Post Architecture) | 30.64 | 12.9 | 2.4 |
| FPA | 10.26 | 6.0 | 1.7 |
| UCP | 2.22 | 1.1 | 2.0 |

**Анализ:**
- UCP дает самую оптимистичную оценку, так как учитывает только функциональные требования
- COCOMO II дает более реалистичную оценку, учитывая инфраструктурный код
- FPA занимает промежуточное положение

## 8. Выводы

1. **Общее количество UCP:** 125 Use Case Points
2. **Трудоемкость разработки:** 2.22 чел×мес (355 часов)
3. **Время разработки:** 1.1 месяца при команде из 2 человек
4. **Метод UCP** подходит для оценки функциональной части проекта, но не учитывает инфраструктурный код
5. **Рекомендуется** использовать комбинацию методов UCP и COCOMO для более точной оценки
