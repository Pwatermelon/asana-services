# Практические работы по экономике программной инженерии

## Проект: Каталог асан (Asana Dictionary Service)

Данная папка содержит практические работы, адаптированные для проекта разработки веб-приложения "Каталог асан" - информационной системы для хранения, поиска и управления информацией об асанах йоги.

### Описание проекта

**Каталог асан** - это веб-приложение, предназначенное для:
- Хранения информации об асанах йоги (названия на русском, санскрите, транслитерация, определения)
- Управления источниками информации (книги, статьи, видео)
- Добавления фотографий асан
- Поиска и фильтрации асан
- Модерации контента экспертами
- Управления пользователями администраторами

**Технологический стек:**
- Backend: Python, FastAPI, PostgreSQL, RDF/OWL (онтология)
- Frontend: React, JavaScript, Vite
- Инфраструктура: Docker, Nginx, MinIO (S3)

### Структура практических работ

1. **Практическая работа 2** - Конструктивная модель стоимости COCOMO
2. **Практическая работа 3** - Оценка стоимости методом функциональных точек (FPA)
3. **Практическая работа 4** - Метод PERT
4. **Практическая работа 5** - Оценка проекта методом UCP (Use Case Points)
5. **Практическая работа 6** - Анализ эффективности инвестиционного проекта
