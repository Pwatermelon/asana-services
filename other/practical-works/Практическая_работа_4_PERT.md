**Расчет средней трудоемкости критического пути:**
```
E = Σ Ei = 0.20 + 1.05 + 1.53 + 0.52 + 2.08 + 2.58 + 1.53 + 1.05 + 1.53 + 1.05 + 1.62 + 0.32 + 0.32
E = 14.82 месяца
```

**Расчет среднеквадратичного отклонения:**
```
CKO = √(Σ CKOi²) = √(0.033² + 0.117² + 0.133² + 0.083² + 0.250² + 0.250² + 0.133² + 0.117² + 0.133² + 0.117² + 0.217² + 0.050² + 0.050²)

CKO = √(0.2773) = 0.527 месяца
```

**Оценка трудоемкости с вероятностью 95%:**
```
E95% = E + 2 × CKO = 14.82 + 2 × 0.527 = 14.82 + 1.054 = 15.87 месяца
```
