## Описание проекта

**Проект:** Разработка и внедрение веб-приложения "Каталог асан" - информационной системы для хранения и управления информацией об асанах йоги.

## 1. Определение годовой ставки дисконтирования

**Кумулятивный метод расчета:**
```
d = e + i + r
```

**Исходные данные:**
- e (ставка дохода банковского депозита) = 8.5% (средняя ставка по депозитам крупных банков на 1 год)
- i (темп инфляции) = 6.0% (официальные данные Росстата)
- r (премия за риск) = 12.0% (IT-проект средней сложности)

**Расчет:**
```
d = 8.5% + 6.0% + 12.0% = 26.5% (0.265)
```

## 5. Расчет показателей эффективности проекта

### 5.1. Чистая приведенная стоимость (NPV)

**Расчет:**
```
NPV = Σ(DCFt) = -3739000 - 617800 - 417500 - 340800 - 282200 - 237400 = -5634700 руб.
```

**Вывод:** NPV < 0, проект неэффективен с точки зрения чистой приведенной стоимости.

### 5.2. Внутренняя ставка доходности (IRR)

**Расчет IRR (методом подбора):**

При d = 0.265: NPV = -5634700 руб.
При d = -0.10: NPV ≈ 0 (проект безубыточен)

**IRR ≈ -10%**

**Вывод:** IRR < d, проект неэффективен. Отрицательная IRR указывает на то, что проект не окупается.

## 6. Анализ результатов

### 6.1. Причины отрицательной эффективности

1. **Высокие инвестиционные затраты** (3.74 млн руб.) при относительно небольшой экономии
2. **Высокие эксплуатационные затраты** (990000-998000 руб/год) превышают экономию
3. **Низкая экономия** от внедрения системы (208200-228200 руб/год)
4. **Высокая ставка дисконтирования** (26.5%) снижает ценность будущих денежных потоков

### 6.2. Рекомендации по улучшению эффективности

1. **Снижение инвестиционных затрат:**
   - Использование облачных сервисов вместо покупки серверов: экономия ~600000 руб.
   - Аренда оборудования вместо покупки: экономия ~400000 руб.

2. **Снижение эксплуатационных затрат:**
   - Оптимизация использования облачных сервисов: экономия ~100000 руб/год
   - Автоматизация процессов: экономия ~50000 руб/год

3. **Увеличение экономии:**
   - Расширение использования системы: дополнительная экономия ~100000 руб/год
   - Монетизация (если возможно): дополнительные доходы
