Редактор плана (JSON)

Нажми “Пересчитать по JSON” после правок
Формат задачи: { "id": "2.1", "name": "...", "days": 4, "hours": 32, "preds": ["1.1","1.2"] }
Что считается:
  • ES/EF — ранние сроки (по максимуму предшественников)
  • LS/LF — поздние сроки (по дедлайну проекта)
  • Резерв = LS − ES
  • Критические — резерв = 0
Подсказки:
  • У задач без предшественников preds: [].
  • Если сделаешь цикл в зависимостях — CPM выдаст ошибку.
  • Можно оставить hours = 0, это не ломает расчёт.
